# Mawww-AM

Manual Activation Service Website — Request aktivasi via web, owner proses manual, user cek status.

## Live Demo

- **User Page**: https://mawww-am.vercel.app
- **Owner Panel**: https://mawww-am.vercel.app/admin

## Kontak Owner

## Fitur

- Form request aktivasi (email + WA + note)
- Notifikasi otomatis ke owner via WhatsApp
- User cek status request by email
- Admin panel dengan login
- Kelola status: pending / processing / approved / rejected
- Klik nomor WA user langsung dari panel
- Responsive mobile

## Deploy

Repo ini siap deploy ke Vercel. Set environment variable `ADMIN_PASSWORD` di dashboard Vercel.
